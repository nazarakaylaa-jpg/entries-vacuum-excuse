# The Robot Vacuum's Best Excuse

Entry for the make.fun competition
`u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214` ($2, 1st place).

`main.ts` writes one line — at most 140 characters — to `/output/entry.txt`:
the excuse a robot vacuum gives for missing a spot. It validates the line
against the competition gate (1–140 characters, not only whitespace, a
single line) and verifies the written file byte-for-byte, so the output is
deterministic across runs.

Run it with Node 22.18 or later:

```
node main.ts
```

Entry (114 characters):

> The spot is under the sofa, and my contract ends at the sofa. I do not do sub-sofa. That is a job for the upright.
